# M115 – Lab 1: Phishing URL Detection

## About this lab

In this lab, I worked with the PhiUSIIL Phishing URL Dataset to explore how machine learning can help identify phishing websites.

The main goal was to analyze the dataset, train different Logistic Regression models, and understand which features are useful for detecting phishing URLs.

I also used SHAP to better understand the model's predictions and explored different classification thresholds from a SOC perspective.

## Dataset

**PhiUSIIL Phishing URL Dataset**

- [Kaggle Dataset](https://www.kaggle.com/datasets/kaggleprollc/phishing-url-websites-dataset-phiusiil)
- [UCI Repository](https://archive.ics.uci.edu/dataset/967/phiusiil-phishing-url-dataset)

The dataset contains information about legitimate and phishing websites.

For this project, I used the following target mapping:

- `label = 1` → Legitimate website
- `label = 0` → Phishing website
- `IsPhishing = 1` → Phishing
- `IsPhishing = 0` → Legitimate

## What I did

The notebook covers the following tasks:

1. Explored the dataset and checked for missing values and duplicates.
2. Analyzed the distribution of legitimate and phishing websites.
3. Examined different features and their relationships with the target.
4. Prepared the data for machine learning.
5. Split the dataset into training and testing sets.
6. Trained and compared five Logistic Regression models.
7. Tested L1 regularization and feature selection.
8. Analyzed model coefficients and odds ratios.
9. Used SHAP to explain model predictions.
10. Tested different classification thresholds.
11. Discussed how the results could be used in a SOC environment.
